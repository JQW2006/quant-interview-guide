# 第一部分：算法

## 1. 复杂度分析

### 1.1 大 O 记号

$T(n)=O(f(n))$ 表示存在常数 $c$ 和 $n_0$，当 $n\ge n_0$ 时 $T(n)\le c\,f(n)$。面试中一般说"最坏情况"复杂度；哈希表等结构说"均摊"或"期望"复杂度。

| 复杂度 | $n=10^6$ 时的运算量 | 典型算法 |
|---|---|---|
| $O(1)$、$O(\log n)$ | 1、20 | 哈希查找、二分 |
| $O(n)$ | $10^6$ | 遍历、双指针、单调栈 |
| $O(n\log n)$ | $2\times10^7$ | 排序、堆、分治 |
| $O(n^2)$ | $10^{12}$（**不可行**） | 双重循环 |

**经验法则**：C++ 每秒约 $10^8$ 次简单运算，Python 约 $10^7$ 次。所以看到数据范围就能反推要求的复杂度：$n\le 10^5$ 要 $O(n\log n)$ 以内，$n\le 5000$ 可以 $O(n^2)$，$n\le 20$ 可能是 $O(2^n)$ 状态压缩。

### 1.2 主定理（分治递推）

$T(n)=aT(n/b)+O(n^d)$：

| 条件 | 结果 | 例子 |
|---|---|---|
| $d>\log_b a$ | $O(n^d)$ | |
| $d=\log_b a$ | $O(n^d\log n)$ | 归并排序 $a=b=2,d=1$ → $O(n\log n)$ |
| $d<\log_b a$ | $O(n^{\log_b a})$ | Karatsuba 乘法 $a=3,b=2$ → $O(n^{1.585})$ |

### 1.3 均摊分析

动态数组（Python `list`、C++ `vector`）容量满时翻倍扩容。$n$ 次 `append` 的总复制次数 $\le 1+2+4+\cdots+n<2n$，所以**均摊 $O(1)$**。

### 1.4 在量化中的用途

全市场约 5000 只股票、每天 240 根分钟线、10 年约 2500 个交易日——分钟级数据有 $3\times10^9$ 行。$O(n^2)$ 的算法、逐行 `for` 循环在这个量级上都不可行。**量化研究员的编程能力，很大程度上就是"把计算写成向量化、O(n) 或 O(n log n) 的能力"。**

## 2. 线性结构

### 2.1 哈希表

**概念**：用哈希函数把键映射到数组下标，查找、插入、删除**期望 $O(1)$**。Python 的 `dict`、`set`，C++ 的 `unordered_map`。

**最常见的用法：用空间换时间。** "两数之和"暴力是 $O(n^2)$；边遍历边把"已见过的数 → 下标"存进哈希表，每个数只查一次 `target - x`，变成 $O(n)$。

**第二种常见用法：分组计数。** 把满足某种等价关系的元素映射到同一个键，再数每组有几对：大小为 $c$ 的组贡献 $\binom c2$ 对。九坤专场的"可以读通讯稿的组数"就是把条件 $a_i+\text{rev}(a_j)=a_j+\text{rev}(a_i)$ 变形成 $a_i-\text{rev}(a_i)=a_j-\text{rev}(a_j)$，于是以 $a-\text{rev}(a)$ 为键分组。

### 2.2 前缀和

**概念**：$S_0=0,\ S_i=a_1+\cdots+a_i$，则区间和 $a_l+\cdots+a_r=S_r-S_{l-1}$，$O(1)$ 查询。

**推广**：
- **和为 $k$ 的子数组个数**：遍历时统计"之前有多少个前缀和等于 $S_i-k$"，用哈希表，$O(n)$；
- 二维前缀和：$S_{i,j}=S_{i-1,j}+S_{i,j-1}-S_{i-1,j-1}+a_{ij}$；
- **差分**：前缀和的逆运算，用于"区间整体加一个数"。

**量化中的用途**：累计收益 `cumsum`、滚动窗口和 = 两个前缀和相减（`rolling().sum()` 的底层思路）；滚动均值、方差都能用前缀和（$\sum x$ 与 $\sum x^2$）做到 $O(n)$。

### 2.3 双指针

| 类型 | 做法 | 例题 |
|---|---|---|
| 对撞指针 | 左右两端向中间收缩 | 有序数组两数之和、三数之和、盛最多水的容器、接雨水 |
| 快慢指针 | 一个走得快，一个走得慢 | 链表找环、删除重复元素、移动零 |
| 同向指针（滑动窗口） | 右指针扩张，左指针收缩 | 最长无重复子串、最小覆盖子串 |

**为什么对撞指针是对的（以"盛最多水的容器"为例）**：面积 $=(r-l)\min(h_l,h_r)$。若 $h_l<h_r$，则以 $l$ 为左端的所有更窄的容器高度都不超过 $h_l$、宽度更小，不可能更优，于是可以安全地丢掉 $l$。**每一步都排除一整行候选**，这是双指针正确性的通用论证。

### 2.4 滑动窗口

**模板**：
```python
left = 0
for right, x in enumerate(arr):
    加入 x，更新窗口状态
    while 窗口不合法:
        移出 arr[left]，left += 1
    用当前窗口更新答案
```
每个元素最多进出窗口各一次，总复杂度 $O(n)$。

**量化中的用途**：所有 `rolling` 指标都是滑动窗口。固定长度窗口的和、均值、方差可以 $O(1)$ 增量更新；窗口最大值要用**单调队列**（3.2 节）；窗口中位数要用**双堆**（3.3 节）。

## 3. 栈、队列、堆

### 3.1 栈与单调栈

**栈**：后进先出。典型题：括号匹配、表达式求值、最小栈（再维护一个"当前最小值"栈）。

**单调栈**：栈内元素保持单调。用于求"**每个元素左边/右边第一个比它大（小）的元素**"，$O(n)$。

以"每日温度"（下一个更高温度在几天后）为例：从左往右扫，栈中存**还没找到答案的下标**，栈内温度单调递减。新温度 $t$ 到来时，把栈顶所有比 $t$ 低的下标弹出——它们的答案就是今天。每个下标进出栈各一次，所以 $O(n)$。

| 题目 | 栈内单调性 | 弹出时得到 |
|---|---|---|
| 下一个更大元素 / 每日温度 | 递减 | 被弹元素右侧第一个更大值 |
| 柱状图中最大矩形 | 递增 | 被弹柱子左右两侧第一个更矮的柱子 → 以它为高的最大宽度 |
| 股票价格跨度 | 递减 | 今天价格向左能覆盖多少天 |

### 3.2 单调队列（滑动窗口最大值）

双端队列 `deque` 中存下标，对应的值**单调递减**：
1. 新元素进来前，把队尾所有比它小的弹出（它们比新元素早过期又更小，永远不会成为最大值）；
2. 队首如果已滑出窗口就弹出；
3. 队首就是当前窗口最大值。

每个元素进出队各一次，$O(n)$。**量化中的用途**：滚动最高价、滚动最大回撤、唐奇安通道（Donchian Channel）。

### 3.3 堆

**概念**：完全二叉树，父节点不大于子节点（小顶堆）。插入、弹出堆顶 $O(\log n)$，取堆顶 $O(1)$，用数组建堆 $O(n)$。Python 的 `heapq` 是小顶堆，大顶堆可以存负数。

| 用途 | 做法 | 复杂度 |
|---|---|---|
| Top-K（第 K 大） | 维护大小为 K 的小顶堆 | $O(n\log K)$ |
| 合并 K 个有序序列 | 堆中存每个序列的当前头部 | $O(N\log K)$ |
| **数据流中位数** | 大顶堆存较小一半，小顶堆存较大一半，大小差不超过 1 | 插入 $O(\log n)$，查询 $O(1)$ |
| 滑动窗口中位数 | 双堆 + **延迟删除**（记录待删元素，到堆顶时再删） | $O(n\log n)$ |

**另一种方法——快速选择（Quickselect）**：类似快排，但每次只递归进一边，期望 $O(n)$，最坏 $O(n^2)$。`np.partition` 就是这个思路。

**量化中的用途**：截面 Top-K 选股、多路行情按时间戳合并（K 个交易所的 tick 归并）、滚动中位数（MAD 去极值）、订单簿的最优买卖价。

## 4. 二分、链表、树、图

### 4.1 二分查找

**概念**：在**有单调性**的区间上，每次排除一半。$O(\log n)$。

**写对二分的关键是固定区间含义**。推荐统一用"左闭右开 + 找第一个满足条件的位置"：
```python
def lower_bound(a, x):          # 第一个 >= x 的位置
    lo, hi = 0, len(a)          # 答案在 [lo, hi] 中
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] >= x: hi = mid
        else: lo = mid + 1
    return lo
```
Python 的 `bisect.bisect_left` 就是这个函数。**注意**：`bisect.insort` 查找是 $O(\log n)$，但插入要移动元素，是 **$O(n)$**（九坤笔试考过）。

**答案二分**：当"答案为 $x$ 是否可行"关于 $x$ 单调时，对答案二分。例："分割数组的最大值"——给定上限 $m$，贪心检查能否切成不超过 $k$ 段，$m$ 越大越容易可行。

### 4.2 链表

| 技巧 | 用途 |
|---|---|
| 哑节点（dummy head） | 统一处理头节点被删除或改变的情况 |
| 快慢指针 | 找中点、判断环、找环入口、倒数第 $k$ 个节点 |
| 原地反转 | `prev, cur = None, head; while cur: cur.next, prev, cur = prev, cur, cur.next` |

**环入口的推导**：设头到入口距离 $a$，入口到相遇点 $b$，环长 $c$。相遇时慢指针走了 $a+b$，快指针走了 $2(a+b)=a+b+kc$，所以 $a=kc-b$：一个指针从头出发、一个从相遇点出发，同速前进，必在入口相遇。

### 4.3 二叉树

**递归的思考方式**：假设函数对左右子树已经返回了正确结果，只考虑如何在当前节点合并。

| 遍历 | 顺序 | 用途 |
|---|---|---|
| 前序 | 根-左-右 | 复制树、序列化 |
| 中序 | 左-根-右 | **BST 的中序遍历是有序的**（验证 BST、第 K 小） |
| 后序 | 左-右-根 | 需要子树信息才能算当前节点：深度、直径、最大路径和 |
| 层序（BFS） | 按层 | 按层打印、右视图、最小深度 |

**"返回值"与"全局答案"分离**是后序遍历的通用套路。以"二叉树最大路径和"为例：函数返回"从当前节点向下走的一条链的最大和"（只能选一边），而全局答案在当前节点处用"左链 + 自己 + 右链"更新。

### 4.4 图

**存储**：邻接表 `graph = defaultdict(list)`。网格图不用显式建图，直接用方向数组。

| 算法 | 复杂度 | 适用 |
|---|---|---|
| BFS | $O(V+E)$ | 无权图最短路、按层扩散（多源 BFS） |
| DFS | $O(V+E)$ | 连通分量、找环、回溯 |
| **拓扑排序（Kahn）** | $O(V+E)$ | 有向无环图（DAG）上的依赖顺序；**能检测环** |
| Dijkstra | $O(E\log V)$ | 非负权最短路 |
| 并查集 | 近似 $O(1)$ | 动态连通性、带权关系（如汇率换算） |

**Kahn 算法**：统计每个点的入度，把入度为 0 的点入队；每弹出一个点就把它的后继入度减 1，减到 0 的入队。如果最后输出的点数少于总点数，说明有环。九坤考过的"任务依赖排序"就是这道题。

**量化中的用途**：因子计算的依赖图（一个因子依赖另几个因子，调度时要按拓扑序计算，这正是 Airflow、Qlib 表达式引擎的核心）；股票关联图（供应链、同行业）；汇率套利 = 在 $-\log(\text{汇率})$ 为边权的图上找负环（Bellman-Ford）。

## 5. 动态规划、贪心、位运算

### 5.1 动态规划的四步法

1. **定义状态**：$dp[i]$ 或 $dp[i][j]$ 表示什么（这是最难、最关键的一步）；
2. **写转移方程**：$dp[i]$ 怎样由更小的状态得到；
3. **确定初始值和边界**；
4. **确定计算顺序**，再考虑能否压缩空间。

| 类型 | 状态 | 转移 | 例题 |
|---|---|---|---|
| 线性 | $dp[i]$：以 $i$ 结尾 / 前 $i$ 个 | 由 $dp[i-1]$ 或 $dp[j],j<i$ | 最大子数组和、打家劫舍、LIS |
| 双序列 | $dp[i][j]$：前 $i$ 个和前 $j$ 个 | 比较 $a_i$、$b_j$ | LCS、编辑距离 |
| 背包 | $dp[j]$：容量 $j$ 时的最优值 | 0-1 背包**倒序**遍历容量，完全背包正序 | 分割等和子集、零钱兑换 |
| 状态机 | $dp[i][\text{状态}]$ | 状态之间转移 | **股票买卖系列** |
| 区间 | $dp[l][r]$ | 枚举分割点 | 最长回文子串、戳气球 |

### 5.2 股票买卖系列（天演考过）

统一状态：$\text{hold}[i]$ = 第 $i$ 天结束时持有股票的最大收益，$\text{free}[i]$ = 不持有的最大收益。

| 题号 | 限制 | 转移要点 |
|---|---|---|
| 121 | 只能交易一次 | 记录历史最低价，$O(n)$ |
| 122 | 不限次数 | 所有上涨日的涨幅之和（贪心），或状态机 |
| 123 / 188 | 最多 $k$ 次 | 状态加一维：$\text{hold}[j]$、$\text{free}[j]$，$j$ 为已完成交易次数 |
| 309 | 卖出后冷冻一天 | 买入时用 $\text{free}[i-2]$ |
| 714 | 每次交易有手续费 | 卖出时减去手续费 |

**量化联系**：手续费版本说明了**交易成本会让最优策略减少交易**——这正是因子换手率与扣费后收益权衡的简化版。

### 5.3 鸡蛋掉落（九坤笔试原题）

**题目**：$k$ 个鸡蛋，$n$ 层楼，求最坏情况下确定临界楼层所需的最少扔蛋次数（九坤：$k\le100$，$n\le10^4$，时限 2 秒）。

**直接定义的 DP 会超时**：$dp[k][n]=1+\min_{x}\max(dp[k-1][x-1],dp[k][n-x])$，状态 $kn=10^6$，每个状态枚举 $x$ 又要 $O(n)$，共 $10^{10}$。复盘作者正是在这里超时的。

**换一个状态（反过来问）**：$f[t][k]$ = 用 $t$ 次、$k$ 个蛋**最多能确定多少层**。扔一次：碎了，下面能确定 $f[t-1][k-1]$ 层；没碎，上面能确定 $f[t-1][k]$ 层；加上这一层本身：
$$f[t][k]=f[t-1][k-1]+f[t-1][k]+1$$
找最小的 $t$ 使 $f[t][k]\ge n$。$t$ 最多为 $n$，实际上 $k\ge2$ 时 $t=O(\sqrt n)$ 级别，复杂度 $O(k\cdot t)$，瞬间出结果。

**教训**："正着定义"不行时，**交换状态与答案的角色**（"$t$ 次最多能做多少"而不是"做 $n$ 需要几次"）是 DP 的常见优化。数学专题 7.7 节有两个蛋的闭式解 $\frac{t(t+1)}2\ge n$，与这里 $k=2$ 时的 $f[t][2]=\frac{t(t+1)}{2}$ 一致。

### 5.4 贪心

**概念**：每一步做局部最优选择，并且能证明局部最优能导出全局最优。证明常用**交换论证**：假设最优解在某一步和贪心选择不同，把它换成贪心选择后不会变差。

| 题目 | 贪心策略 |
|---|---|
| 跳跃游戏 | 维护能到达的最远位置 |
| 区间调度（最多不重叠区间） | 按**右端点**排序，能选就选 |
| 加油站 | 总油量 $\ge$ 总消耗则有解；从累计油量最低点的下一站出发 |
| 股票买卖 II | 所有正的日涨幅都吃掉 |

### 5.5 位运算

| 技巧 | 含义 |
|---|---|
| `x & (x - 1)` | 去掉最低位的 1；`x & (x-1) == 0` 判断 2 的幂 |
| `x & -x` | 取最低位的 1（树状数组的核心） |
| `a ^ a = 0`，`a ^ 0 = a` | 成对出现的数异或抵消 → "只出现一次的数字" |
| `mask >> i & 1` | 判断第 $i$ 位；用整数表示子集（状态压缩 DP） |

### 5.6 随机算法（量化面试特色题）

| 题目 | 方法 |
|---|---|
| 用 rand7 实现 rand10 | 拒绝采样：$(\text{rand7}()-1)\times7+\text{rand7}()$ 均匀分布在 1–49，只接受 1–40，对 10 取模 |
| 蓄水池抽样 | 第 $i$ 个元素以 $k/i$ 的概率替换池中随机一个；归纳法证明每个元素被选中的概率都是 $k/n$ |
| Fisher-Yates 洗牌 | `for i in range(n-1, 0, -1): j = randint(0, i); swap(a[i], a[j])`，$n!$ 种排列等概率 |

# 第二部分：Python 与量化数据处理

## 6. Python 语言要点

### 6.1 一切都是对象，变量是"标签"

Python 的变量名是对象的引用。`b = a` 不复制对象，只是让 `b` 也指向同一个对象。

| 类型 | 可变？ | 例子 |
|---|---|---|
| 不可变 | 否 | `int`、`float`、`str`、`tuple`、`frozenset` |
| 可变 | 是 | `list`、`dict`、`set`、NumPy 数组、DataFrame |

`==` 比较值，`is` 比较是否为同一个对象。小整数（$-5$ 到 $256$）被缓存，所以 `a is b` 对小整数常为 `True`，这是实现细节，**不要依赖**。

### 6.2 深拷贝与浅拷贝

| 操作 | 新建了什么 | 内层可变对象 |
|---|---|---|
| `b = a` | 什么都没新建 | 共享 |
| `b = a.copy()`、`list(a)`、`a[:]`、`copy.copy(a)` | 新的外层容器 | **共享** |
| `copy.deepcopy(a)` | 递归复制所有层 | 独立 |

**量化中的坑**：`params = [[0]*3]*4` 得到的 4 行是**同一个列表**，改一行四行都变；把一份参数字典 `dict.copy()` 后修改其中的嵌套列表，原参数也会被改。NumPy 中切片 `a[1:3]` 是**视图**（共享内存），花式索引 `a[[1,2]]` 和布尔索引是**副本**。

### 6.3 可变默认参数

```python
def add(x, lst=[]):     # 默认值在函数定义时只创建一次
    lst.append(x)
    return lst
add(1)  # [1]
add(2)  # [1, 2]   ← 上一次的列表还在
```
**正确写法**：`def add(x, lst=None): if lst is None: lst = []`。

### 6.4 闭包与延迟绑定

```python
fs = [lambda: i for i in range(3)]
[f() for f in fs]   # [2, 2, 2]
```
闭包捕获的是**变量**而不是值，调用时 `i` 已经是 2。修正：`lambda i=i: i`（用默认参数在定义时绑定）。

### 6.5 装饰器

**概念**：装饰器是"接收函数、返回新函数"的函数，`@deco` 等价于 `f = deco(f)`。

```python
import functools, time
def timer(func):
    @functools.wraps(func)          # 保留原函数的名字和文档
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__} 用时 {time.perf_counter() - t0:.3f}s")
        return result
    return wrapper
```
**量化中的用途**：计时、缓存（`functools.lru_cache` 缓存因子计算结果）、重试（网络取数失败时重试）、注册因子（`@register_factor("mom20")` 把函数放进因子库字典）、日志。

### 6.6 生成器

**概念**：含 `yield` 的函数调用后返回生成器，**按需逐个产出值**，不把所有结果放进内存。`(x*x for x in data)` 是生成器表达式。

**量化中的用途**：逐日读取大文件（`for chunk in pd.read_csv(path, chunksize=10**6)`）、逐个产出 walk-forward 的训练/测试区间、模拟 tick 数据流。

### 6.7 GIL

**概念**：CPython 的全局解释器锁（Global Interpreter Lock）保证同一时刻只有一个线程执行 Python 字节码。

| 任务类型 | 多线程有用吗？ | 推荐方案 |
|---|---|---|
| I/O 密集（下载数据、读数据库） | **有用**，等 I/O 时会释放 GIL | `threading`、`asyncio` |
| CPU 密集（纯 Python 循环计算） | **没用** | `multiprocessing`、`concurrent.futures.ProcessPoolExecutor` |
| 数值计算 | NumPy 等 C 扩展在内部释放 GIL | 向量化、Numba、Cython |

补充：Python 3.13 起提供实验性的"无 GIL"构建（PEP 703，free-threaded），但默认发行版仍有 GIL。

### 6.8 内置容器复杂度

| 操作 | `list` | `dict` / `set` | `collections.deque` |
|---|---|---|---|
| 按下标取值 | $O(1)$ | — | $O(n)$ |
| 尾部追加 / 弹出 | 均摊 $O(1)$ | — | $O(1)$ |
| **头部插入 / 弹出** | **$O(n)$** | — | $O(1)$ |
| `x in` | $O(n)$ | 期望 $O(1)$ | $O(n)$ |
| 排序 | $O(n\log n)$（Timsort，稳定） | — | — |

**所以**：BFS 的队列一定用 `deque`，不要用 `list.pop(0)`。

## 7. NumPy：向量化与广播

### 7.1 为什么要向量化

Python 循环每一步都要做类型检查、对象创建；NumPy 把循环放在 C 里，对连续内存做批量运算（还能用 SIMD）。通常快 **10–100 倍**。

```python
# 慢：逐元素循环
out = [a[i] * b[i] for i in range(n)]
# 快：向量化
out = a * b
```

### 7.2 广播规则

两个数组从**最后一维**开始对齐：每一维要么相等，要么其中一个是 1（或缺失），是 1 的那一维会被"拉伸"。

| 形状 A | 形状 B | 结果 |
|---|---|---|
| `(T, N)` | `(N,)` | `(T, N)`：每行减去同一个向量 |
| `(T, N)` | `(T, 1)` | `(T, N)`：每行减去该行自己的值（**截面去均值**） |
| `(T, N)` | `(T,)` | **报错**（最后一维 $N\ne T$）→ 要先 `reshape(-1, 1)` 或 `[:, None]` |

```python
X = np.random.randn(250, 5000)                          # 250 天 × 5000 只股票
Z = (X - X.mean(axis=1, keepdims=True)) / X.std(axis=1, keepdims=True)   # 截面 z-score
```

### 7.3 常用技巧

| 需求 | 写法 |
|---|---|
| 滚动窗口（不复制内存） | `np.lib.stride_tricks.sliding_window_view(x, w)` → 形状 `(n-w+1, w)` |
| 条件赋值 | `np.where(cond, a, b)` |
| 去极值 | `np.clip(x, lo, hi)` |
| 处理缺失值 | `np.nanmean`、`np.nanstd`；**`NaN != NaN`**，判断用 `np.isnan` |
| 部分排序 | `np.partition(x, k)`、`np.argpartition`：$O(n)$ 取 Top-K |
| 截面排名 | `x.argsort(axis=1).argsort(axis=1)`（无并列时）；有并列用 `scipy.stats.rankdata` |
| 协方差矩阵 | `np.cov(R, rowvar=False)` 或 `Rc.T @ Rc / (T-1)` |

### 7.4 视图与副本

切片 `a[1:5]`、`a.T`、`reshape`（能不复制时）返回**视图**，修改会影响原数组；花式索引、布尔索引返回**副本**。`np.shares_memory(a, b)` 可以检查。

## 8. pandas：量化数据处理的标准写法

### 8.1 两种数据形态

| 形态 | 结构 | 适合 |
|---|---|---|
| **宽表** | `index` = 日期，`columns` = 股票代码 | 截面运算（`axis=1`）、时序运算（`rolling`、`shift`） |
| **长表** | 列为 `date, code, factor, ret, industry, ...` | `groupby`、`merge`、回归、机器学习 |

转换：`wide = long.pivot(index="date", columns="code", values="factor")`；`long = wide.stack().rename("factor").reset_index()`。

### 8.2 时间方向：`shift` 与未来函数

**最重要的一条**：用第 $t$ 日的因子预测第 $t+1$ 日的收益。
```python
fwd_ret = close.pct_change().shift(-1)      # 下一日收益，对齐到 t 日
# 或者：因子滞后一天，与当日收益对齐
factor_lag = factor.shift(1)
```
`shift(-1)` 把未来数据拉到今天，**只能用于构造标签**，绝不能出现在特征里。

### 8.3 `groupby` 的三种用法

| 方法 | 输出形状 | 用途 |
|---|---|---|
| `agg` / `mean` | 每组一行 | 每日的 IC、每个行业的平均收益 |
| `transform` | **与原数据同形** | 截面排名、截面 z-score、行业内去均值 |
| `apply` | 任意 | 复杂逻辑（如每日一次回归）；慢，能用前两个就不用它 |

```python
df["z"] = df.groupby("date")["factor"].transform(lambda s: (s - s.mean()) / s.std())
df["rank"] = df.groupby("date")["factor"].rank(pct=True)
df["ind_demean"] = df["factor"] - df.groupby(["date", "industry"])["factor"].transform("mean")
```

### 8.4 `rolling`、`expanding`、`ewm`

```python
vol20 = ret.rolling(20, min_periods=15).std() * np.sqrt(252)   # 年化波动
mom = close / close.shift(20) - 1                                # 20 日动量
ema = close.ewm(halflife=10).mean()                              # 指数加权
beta = ret_i.rolling(60).cov(ret_m) / ret_m.rolling(60).var()    # 滚动 beta
```

### 8.5 `merge` 与时间对齐

| 函数 | 用途 |
|---|---|
| `merge(on=..., how="left")` | 按键合并（日期 + 代码） |
| `merge_asof(by="code", on="date", direction="backward")` | **按时间向前找最近一条记录**：财报按**公告日**对齐到交易日，保证 point-in-time |
| `join` | 按索引合并 |
| `concat` | 上下或左右拼接 |

**坑**：`merge` 时键有重复会产生笛卡尔积，行数暴增；合并前先 `assert df.duplicated(["date","code"]).sum() == 0`。

### 8.6 性能与易错点

1. **不要 `iterrows`**：慢 100 倍以上；用向量化、`groupby`、`np.where`。
2. **链式赋值**：`df[df.a > 0]["b"] = 1` 不会修改 `df`。pandas 3.0 起默认启用**写时复制（Copy-on-Write）**，这种写法**永远不会生效**（旧版本会给出 `SettingWithCopyWarning`）。正确写法：`df.loc[df.a > 0, "b"] = 1`。
3. **`NaN` 的处理**：`mean`、`corr` 默认跳过 `NaN`；`rank` 保留 `NaN`；`pct_change` 在 pandas 2.1 之后默认不再前向填充。
4. **类型**：股票代码用字符串（`"000001"` 读成整数会丢前导零），`read_csv(dtype={"code": str})`。
5. **大数据**：用 parquet 代替 csv；`category` 类型存行业；更大规模用 Polars。

### 8.7 量化场景的标准流水线

题库 M 章的每道题都可以直接运行。完整流程是：
```
原始因子 → 去极值（MAD）→ 标准化（z-score / rank）→ 行业市值中性化（截面回归取残差）
       → IC / RankIC 序列 → ICIR、t 值 → 分层回测（qcut 分 5 组）→ 多空净值、最大回撤、换手率
```

## 9. C++ 基础

> 国内 QR 岗位以 Python 为主，但九坤、宽德、灵均的笔试含 C++ 题，高频岗面试必问。以下是"QR 够用"的范围。

### 9.1 指针与引用

| | 指针 `int* p` | 引用 `int& r` |
|---|---|---|
| 能否为空 | 能（`nullptr`） | 不能，必须初始化 |
| 能否改指向 | 能 | 不能，绑定后终身不变 |
| 取值 | `*p` | 直接用 `r` |
| `sizeof` | 指针大小（64 位下 8 字节） | 被引用对象的大小 |

**函数传参**：大对象用 `const T&`（避免拷贝且不能修改）；需要修改用 `T&`；可选参数用指针。

### 9.2 虚函数与多态

- 基类中声明 `virtual` 的函数，通过**基类指针或引用**调用时，会在运行时根据对象的实际类型调用派生类版本。
- **实现**：每个含虚函数的类有一张**虚函数表（vtable）**，每个对象有一个指向它的**虚表指针（vptr）**。调用时多一次间接寻址，并且通常**无法内联**。
- **基类析构函数必须是 `virtual`**：否则 `delete base_ptr` 只调用基类析构，派生类资源泄漏（未定义行为）。
- 纯虚函数 `virtual void f() = 0;` 使类成为抽象类，不能实例化。
- **低延迟场景**：热路径上避免虚函数，改用模板（CRTP，编译期多态）。

### 9.3 RAII 与智能指针

**RAII**（Resource Acquisition Is Initialization）：资源的生命周期绑定到对象的生命周期，构造时获取、析构时释放。即使抛异常，析构函数也会执行，所以不会泄漏。

| 智能指针 | 所有权 | 要点 |
|---|---|---|
| `unique_ptr<T>` | 独占 | 不能拷贝，只能移动；零额外开销；**首选** |
| `shared_ptr<T>` | 共享，引用计数 | 计数是原子操作，有开销；用 `make_shared` 创建 |
| `weak_ptr<T>` | 不拥有 | 不增加计数；用来**打破循环引用** |

**循环引用**：A 持有指向 B 的 `shared_ptr`，B 也持有指向 A 的 `shared_ptr`，两者计数永不为 0，内存泄漏。解决：其中一方改为 `weak_ptr`。

### 9.4 移动语义

- **左值**有名字、能取地址；**右值**是临时对象。`T&&` 是右值引用。
- **移动构造** `T(T&& other)`：直接"偷走" `other` 的资源（例如把指针拿过来、把 `other` 的指针置空），避免深拷贝。`vector` 的移动是 $O(1)$，拷贝是 $O(n)$。
- `std::move(x)` **本身不移动任何东西**，只是把 `x` 转换成右值引用，让移动构造函数有机会被调用。移动后 `x` 处于"有效但未指定"的状态。
- **Rule of 0/3/5**：如果自定义了析构、拷贝构造、拷贝赋值、移动构造、移动赋值中的任何一个，通常五个都要考虑；最好的做法是都不写，让成员（如智能指针、容器）自己管理（Rule of 0）。

### 9.5 STL 容器复杂度

| 容器 | 底层 | 查找 | 插入/删除 | 备注 |
|---|---|---|---|---|
| `vector` | 动态数组 | 下标 $O(1)$ | 尾部均摊 $O(1)$，中间 $O(n)$ | 扩容时迭代器失效；**缓存友好**，默认首选 |
| `deque` | 分段数组 | 下标 $O(1)$ | 头尾 $O(1)$ | |
| `list` | 双向链表 | $O(n)$ | 已知位置 $O(1)$ | 缓存不友好 |
| `map` / `set` | **红黑树** | $O(\log n)$ | $O(\log n)$ | 有序；订单簿按价格排序常用 |
| `unordered_map` | 哈希表 | 期望 $O(1)$，最坏 $O(n)$ | 期望 $O(1)$ | 负载因子过高时 rehash |
| `priority_queue` | 二叉堆 | 堆顶 $O(1)$ | $O(\log n)$ | 默认大顶堆 |

### 9.6 其他常问点

- `const` 的位置：`const int* p`（指向的值不能改）、`int* const p`（指针本身不能改）；`const` 成员函数不修改对象状态。
- 栈与堆：局部变量在栈上，自动释放；`new` 在堆上，需要 `delete`（或交给智能指针）。
- `struct` 与 `class` 唯一的区别是默认访问权限（`public` / `private`）。
- `inline`、`constexpr`（编译期计算）、模板（编译期多态，代码膨胀）。

## 10. 计算机基础

### 10.1 浮点数（IEEE 754）

**表示**：$(-1)^s\times 1.f\times 2^{e-\text{bias}}$。

| 类型 | 符号位 | 指数位 | 尾数位 | 有效十进制位数 |
|---|---|---|---|---|
| float32 | 1 | 8 | 23 | 约 7 位 |
| float64 | 1 | 11 | 52 | 约 15–16 位 |

**能精确表示的小数**：只有形如 $\frac{m}{2^k}$ 的数（且位数够用）。$0.5=2^{-1}$、$0.75$、$0.125$ 可以精确表示；**$0.1$、$0.2$、$0.3$ 都不能**（二进制是无限循环小数）。所以 `0.1 + 0.2 != 0.3`，比较浮点数要用 `abs(a - b) < eps` 或 `math.isclose`。九坤考过这道选择题。

**量化中的坑**：
1. **大数吃小数**：$10^{16}+1=10^{16}$（float64），累加很多小收益时误差积累 → 用 `math.fsum` 或 Kahan 求和；
2. 价格比较：`price == 10.01` 可能为假，交易系统里价格常用整数（以"分"或最小变动价位为单位）存储；
3. **float32 存储数据**能省一半内存，但累计收益、协方差等计算要转成 float64。

### 10.2 进程与线程

| | 进程 | 线程 |
|---|---|---|
| 定义 | 资源分配的基本单位 | CPU 调度的基本单位 |
| 内存 | 独立地址空间 | 共享所在进程的内存 |
| 创建与切换开销 | 大 | 小 |
| 通信 | IPC：管道、消息队列、共享内存、socket、信号 | 直接读写共享变量，需要加锁 |
| 崩溃影响 | 不影响其他进程 | 可能拖垮整个进程 |

**并发问题**：
- **竞态条件**：多个线程同时读写共享数据，结果依赖执行顺序 → 用互斥锁（mutex）、原子操作。
- **死锁的四个必要条件**：互斥、持有并等待、不可剥夺、循环等待。破坏任意一个即可避免，最常用的是**固定加锁顺序**（破坏循环等待）。
- **生产者-消费者**（宽德考过）：共享一个有界缓冲区；缓冲区满时生产者等待、空时消费者等待。用"互斥锁 + 条件变量"或线程安全队列（Python `queue.Queue`）实现。行情接收线程（生产者）+ 策略计算线程（消费者）就是这个模型。

### 10.3 CPU 缓存

- 层次：寄存器 → L1（约 1 ns）→ L2 → L3（约 10 ns）→ 内存（约 100 ns）。**一次缓存未命中可能比一次乘法慢 100 倍**。
- **缓存行**通常 64 字节；访问一个元素会把相邻元素一起读进来，所以**连续访问**快（空间局部性）。
- 例：C/NumPy 默认行优先存储，按行遍历二维数组比按列遍历快很多。
- **伪共享（false sharing）**：两个线程写同一缓存行里的不同变量，缓存行在 CPU 核之间反复失效。解决：对齐填充到 64 字节。
- 宽德面试中问过 cache miss 相关的场景题。

### 10.4 其他

- **虚拟内存**：每个进程看到独立的地址空间，由页表映射到物理内存；缺页时从磁盘调入。
- **TCP 与 UDP**：TCP 可靠、有序、有连接；UDP 无连接、低延迟、可能丢包。交易所行情常用 UDP 组播，下单用 TCP。
- **Linux 常用命令**（灵均考 Linux 基础）：`grep`、`awk`、`sed`、`ps`/`top`、`df`/`du`、`tail -f`、管道 `|`、`nohup`、`crontab`。

## 11. 面试高频问题速查

| 问题 | 要点 |
|---|---|
| 哈希表查找为什么是 $O(1)$？最坏呢？ | 期望 $O(1)$；冲突严重时退化为 $O(n)$（Java 8 起链表过长转红黑树） |
| 快排的复杂度？最坏情况？ | 平均 $O(n\log n)$；有序输入 + 固定选首元素时 $O(n^2)$；随机选主元避免 |
| 哪些排序是稳定的？ | 归并、插入、冒泡、Timsort 稳定；快排、堆排不稳定 |
| 数据流中位数怎么做？ | 大小两个堆，大小差不超过 1 |
| 滑动窗口最大值？ | 单调递减双端队列，$O(n)$ |
| 拓扑排序怎么检测环？ | Kahn 算法输出的点数少于总点数 |
| 鸡蛋掉落怎么优化？ | 状态改为"$t$ 次 $k$ 个蛋最多确定的层数"，$f[t][k]=f[t-1][k-1]+f[t-1][k]+1$ |
| 蓄水池抽样证明？ | 第 $i$ 个被选中 $\frac ki$，之后不被替换 $\prod_{j>i}\frac{j-1}{j}$，乘积 $\frac kn$ |
| 深拷贝与浅拷贝？ | 浅拷贝只复制外层，内层共享；`copy.deepcopy` 递归复制 |
| `def f(x=[])` 有什么问题？ | 默认值只在定义时创建一次，多次调用共享 |
| GIL 是什么？怎么并行？ | 同一时刻一个线程执行字节码；CPU 密集用多进程或 NumPy/Numba |
| 装饰器 / 生成器的用途？ | 计时、缓存、重试、注册；生成器按需产出、省内存 |
| pandas 为什么不能用 `iterrows`？ | 逐行创建 Series 对象，慢；用向量化 / `groupby().transform` |
| `transform` 和 `apply` 的区别？ | `transform` 返回与原数据同形，`apply` 任意 |
| 怎么做截面中性化？ | 每天对行业哑变量 + 对数市值做回归取残差 |
| 怎么避免未来函数？ | 标签用 `shift(-1)`，特征只用 $t$ 时刻已知信息；财报按公告日 `merge_asof` |
| 指针和引用的区别？ | 引用不能为空、不能改绑定 |
| 为什么析构函数要是虚的？ | 通过基类指针删除派生类对象时才能正确析构 |
| `unique_ptr` / `shared_ptr` / `weak_ptr`？ | 独占 / 引用计数共享 / 不拥有、打破循环引用 |
| `std::move` 做了什么？ | 只做类型转换（转成右值引用），真正的移动由移动构造函数完成 |
| `vector` 和 `list` 怎么选？ | 绝大多数情况选 `vector`（连续内存、缓存友好） |
| `map` 和 `unordered_map`？ | 红黑树有序 $O(\log n)$；哈希无序期望 $O(1)$ |
| 0.1 + 0.2 == 0.3 吗？ | 否；只有 $m/2^k$ 形式的数能精确表示 |
| 进程和线程的区别？ | 地址空间是否独立；开销；通信方式 |
| 死锁的条件？ | 互斥、持有并等待、不可剥夺、循环等待 |
| 什么是伪共享？ | 不同线程写同一缓存行导致缓存反复失效 |
