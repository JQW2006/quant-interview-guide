# 统计与计量讲解

统计与计量考查对数据的理解，即如何在噪声中判断信号是否可靠。往年笔试考过回归斜率与 $R^2$、正交多项式、收益率偏度；面试常问 OLS 的推导、基本假设及违反假设的后果。配套练习见[题库](problems.md)。

前置知识：[概率论](../probability/notes.md)中的分布、期望与方差、中心极限定理；线性代数中的矩阵运算（见[数学与智力题](../math/notes.md)第 2 节）。

---

## 1. 统计在做什么

概率论：**已知分布，推断数据**（"公平硬币抛 100 次，正面数的分布？"）。
统计学：**已知数据，推断分布**（"抛了 100 次，60 次正面，硬币公平吗？"）。

| 概念 | 含义 | 例子 |
|---|---|---|
| 总体 | 我们关心的全部对象，有一个未知参数 $\theta$ | 某因子"真实"的预测能力 |
| 样本 | 观察到的数据 $X_1,\dots,X_n$ | 过去 5 年的因子值与收益 |
| 统计量 | 样本的函数 | 样本均值 $\bar X$ |
| 估计量 | 用来猜 $\theta$ 的统计量 $\hat\theta$ | 用样本 IC 均值估计真实 IC |

**量化研究的核心难题**：金融数据**信噪比极低**。日收益的标准差约 2%，而一个好因子带来的超额收益每天可能只有 0.05%。所以统计的作用是回答："**我看到的规律，有多大可能只是噪声？**"

## 2. 描述统计

### 2.1 位置与离散程度

| 统计量 | 公式 | 说明 |
|---|---|---|
| 样本均值 | $\bar X=\frac1n\sum X_i$ | 对极端值敏感 |
| 中位数 | 排序后中间的数 | 稳健（极端值影响小） |
| 样本方差 | $s^2=\frac{1}{n-1}\sum(X_i-\bar X)^2$ | **为什么除以 $n-1$**：见下 |
| 标准差 | $s=\sqrt{s^2}$ | 与数据同单位 |
| 分位数 | 第 $q$ 分位数 | VaR 就是收益分布的分位数 |

**为什么除以 $n-1$（必考）**：

用 $\bar X$ 代替真实均值 $\mu$ 时，$\bar X$ 是"离样本最近"的点，所以 $\sum(X_i-\bar X)^2$ 系统性地小于 $\sum(X_i-\mu)^2$。可以证明：
$$E\Big[\sum(X_i-\bar X)^2\Big]=(n-1)\sigma^2$$
所以除以 $n-1$ 才无偏。直观说法："估计 $\bar X$ 用掉了 1 个**自由度**"。

> 推导：$\sum(X_i-\bar X)^2=\sum(X_i-\mu)^2-n(\bar X-\mu)^2$。取期望：$n\sigma^2-n\cdot\frac{\sigma^2}{n}=(n-1)\sigma^2$。

### 2.2 偏度与峰度（往年·诚奇考过收益偏度）

$$\text{偏度}=E\Big[\Big(\frac{X-\mu}{\sigma}\Big)^3\Big],\qquad\text{峰度}=E\Big[\Big(\frac{X-\mu}{\sigma}\Big)^4\Big]$$

- **偏度**衡量不对称。正态分布偏度为 0。
  - **负偏**：左尾长，"平时小赚、偶尔大亏"。例：卖出期权、指数收益、很多套利策略。
  - **正偏**：右尾长，"平时小亏、偶尔大赚"。例：买入期权、趋势跟踪（CTA）、彩票。
- **峰度**衡量尾部厚度。正态分布峰度为 3，"超额峰度" = 峰度 − 3。
  - 金融收益率普遍**尖峰厚尾**（超额峰度 > 0）：极端行情比正态分布预测的频繁得多。
  - 后果：用正态假设算的 VaR 会**低估**风险。

### 2.3 相关系数

**Pearson 相关系数**：
$$r=\frac{\sum(X_i-\bar X)(Y_i-\bar Y)}{\sqrt{\sum(X_i-\bar X)^2\sum(Y_i-\bar Y)^2}}$$
- 只衡量**线性**关系；对极端值敏感。
- $r=0$ 不代表没有关系（$Y=X^2$，$X$ 对称时 $r=0$）。

**Spearman 秩相关系数**：先把 $X$、$Y$ 各自换成排名，再算 Pearson 相关。
- 稳健，不受极端值影响；衡量**单调**关系。
- **量化中的 Rank IC 就是因子值与下期收益的 Spearman 相关系数**，是评价因子最常用的指标。

**相关矩阵的约束（常考）**：相关矩阵必须**半正定**。所以三个变量的两两相关系数不能随便取，例如不可能两两相关系数都是 −0.9（见题库 A 部分）。

## 3. 抽样分布

假设 $X_1,\dots,X_n$ 独立同分布于 $N(\mu,\sigma^2)$：

| 分布 | 构造 | 用途 |
|---|---|---|
| 正态 | $\bar X\sim N(\mu,\sigma^2/n)$ | $\sigma$ 已知时检验均值 |
| 卡方 $\chi^2_k$ | $k$ 个独立标准正态的平方和 | $\frac{(n-1)s^2}{\sigma^2}\sim\chi^2_{n-1}$，检验方差 |
| $t_k$ | $\dfrac{Z}{\sqrt{\chi^2_k/k}}$（$Z$ 与 $\chi^2$ 独立） | $\dfrac{\bar X-\mu}{s/\sqrt n}\sim t_{n-1}$，**$\sigma$ 未知时检验均值**；回归系数检验 |
| $F_{k_1,k_2}$ | $\dfrac{\chi^2_{k_1}/k_1}{\chi^2_{k_2}/k_2}$ | 回归整体显著性、多个系数联合检验 |

- $t$ 分布比正态分布尾部更厚；自由度 > 30 时与正态几乎一样。
- **标准误（standard error）**：估计量的标准差。均值的标准误是 $\sigma/\sqrt n$（用 $s/\sqrt n$ 估计）。

## 4. 点估计

### 4.1 矩估计（Method of Moments）

用样本矩等于总体矩，解出参数。
**例**：$X\sim U(0,\theta)$，$E[X]=\theta/2$，令 $\bar X=\hat\theta/2$，得 $\hat\theta_{MM}=2\bar X$。

### 4.2 最大似然估计（MLE）：必须会推导

**思想**：选择让"观察到这组数据"的概率最大的参数。

**步骤**：
1. 写似然函数 $L(\theta)=\prod_i f(x_i;\theta)$；
2. 取对数 $\ell(\theta)=\sum_i\ln f(x_i;\theta)$（乘积变求和，好求导）；
3. 令 $\ell'(\theta)=0$ 解出 $\hat\theta$（并检查是最大值）。

**例 1：正态分布**。$\ell(\mu,\sigma^2)=-\frac n2\ln(2\pi\sigma^2)-\frac{1}{2\sigma^2}\sum(x_i-\mu)^2$。
- 对 $\mu$ 求导：$\hat\mu=\bar x$；
- 对 $\sigma^2$ 求导：$\hat\sigma^2=\frac1n\sum(x_i-\bar x)^2$（**除以 $n$，是有偏的**）。

**例 2：伯努利**。$n$ 次中 $k$ 次成功，$\ell(p)=k\ln p+(n-k)\ln(1-p)$，$\hat p=k/n$。

**例 3：均匀分布 $U(0,\theta)$（不能求导的情形）**。$L(\theta)=\theta^{-n}$（当 $\theta\ge\max x_i$），否则为 0。$L$ 关于 $\theta$ 递减，所以 $\hat\theta=\max x_i$。它是有偏的：$E[\max]=\frac{n}{n+1}\theta$，修正为 $\frac{n+1}{n}\max x_i$ 才无偏。

**MLE 的性质**：在正则条件下，MLE **一致**、**渐近正态**、**渐近有效**（方差达到 Cramér-Rao 下界）；而且有**不变性**：$g(\theta)$ 的 MLE 就是 $g(\hat\theta)$。

**MLE 与 OLS 的关系（常考）**：在线性回归中，如果误差服从正态分布，那么 $\beta$ 的 MLE 就是 OLS 估计。因为最大化正态似然 ⇔ 最小化残差平方和。

### 4.3 估计量的好坏

| 性质 | 定义 | 说明 |
|---|---|---|
| 无偏 | $E[\hat\theta]=\theta$ | 平均来说猜得准 |
| 一致 | $n\to\infty$ 时 $\hat\theta\to\theta$ | 数据越多越准。**比无偏更重要** |
| 有效 | 无偏估计中方差最小 | |
| 均方误差 | $\mathrm{MSE}=E[(\hat\theta-\theta)^2]=\text{偏差}^2+\text{方差}$ | **偏差-方差分解** |

**偏差-方差权衡**：有时接受一点偏差，能大幅降低方差，使 MSE 更小。正则化（Ridge、Lasso）、协方差矩阵收缩、贝叶斯先验都基于这个思想。**在信噪比很低的金融数据中，这个思想极其重要。**

**Cramér-Rao 下界**：任何无偏估计的方差 $\ge\frac{1}{nI(\theta)}$，$I(\theta)$ 为 Fisher 信息量。（了解即可。）

## 5. 区间估计与假设检验

### 5.1 置信区间

均值的 95% 置信区间：$\bar X\pm1.96\cdot\frac{s}{\sqrt n}$（$n$ 大时）。

**正确理解**：如果重复抽样很多次，每次都这样构造区间，**约 95% 的区间会包含真实的 $\mu$**。
**错误理解**："$\mu$ 有 95% 的概率落在这个区间里"。（频率学派中 $\mu$ 是固定的数，不是随机变量。）

### 5.2 假设检验的框架

1. **原假设 $H_0$**：通常是"没有效果"（因子无效、均值为 0）；**备择假设 $H_1$**：有效果。
2. 选**检验统计量**，例如 $t=\dfrac{\bar X-\mu_0}{s/\sqrt n}$。
3. 计算 **p 值**：**假设 $H_0$ 成立时，得到至少和观察值一样极端的结果的概率**。
4. p 值 < 显著性水平 $\alpha$（如 0.05），就拒绝 $H_0$。

**p 值的常见误解（面试必问）**：

| 说法 | 对错 |
|---|---|
| p 值是 $H_0$ 为真的概率 | 错。p 值是 $P(\text{数据}\mid H_0)$，不是 $P(H_0\mid\text{数据})$ |
| p 值小说明效果大 | 错。样本量很大时，很小的效果也能有很小的 p 值 |
| p > 0.05 说明 $H_0$ 为真 | 错。只是"证据不足以拒绝" |
| p 值是在 $H_0$ 下看到这么极端数据的概率 | |

### 5.3 两类错误与功效

| | $H_0$ 为真 | $H_0$ 为假 |
|---|---|---|
| 拒绝 $H_0$ | **第一类错误**（假阳性），概率 $\alpha$ | 正确，概率 = **功效** $1-\beta$ |
| 不拒绝 $H_0$ | 正确 | **第二类错误**（假阴性），概率 $\beta$ |

- 在量化中：第一类错误 = 把无效因子当成有效（**上线后亏钱**）；第二类错误 = 错过有效因子。
- **功效**随样本量、效应大小增大而增大。

### 5.4 常用检验

| 检验 | 用途 | 统计量 |
|---|---|---|
| 单样本 t 检验 | 均值是否为 0（如因子收益、策略日收益） | $t=\bar X/(s/\sqrt n)$ |
| 两样本 t 检验 | 两组均值是否相同 | Welch t |
| 配对 t 检验 | 同一对象前后差异 | 差值的单样本 t |
| 卡方检验 | 分布拟合、独立性 | $\sum(O-E)^2/E$ |
| F 检验 | 回归中多个系数是否同时为 0 | 见第 7 节 |
| Jarque-Bera | 是否正态（基于偏度和峰度） | $\frac n6(S^2+\frac{(K-3)^2}4)$ |

**例**：抛硬币 100 次得到 60 次正面。$H_0$: $p=0.5$。$z=\frac{60-50}{\sqrt{100\times0.25}}=2$，双侧 p 值约 0.046，在 5% 水平下拒绝。

## 6. 多重检验：量化研究的头号陷阱

**问题**：检验 100 个**完全无效**的因子，每个在 5% 水平下检验，期望有 5 个"显著"。只报告这 5 个，就是 **p-hacking / 数据挖掘偏差**。

量化中的多重检验无处不在：试很多因子、很多参数、很多回测区间、很多模型。

**对策**：

| 方法 | 做法 | 特点 |
|---|---|---|
| Bonferroni | 每个检验用 $\alpha/m$ 的门槛 | 控制"至少一个假阳性"的概率（FWER），很保守 |
| Holm | 逐步版 Bonferroni | 比 Bonferroni 功效高 |
| Benjamini-Hochberg (BH) | p 值排序，找最大的 $k$ 使 $p_{(k)}\le\frac{k}{m}\alpha$ | 控制**错误发现率**（FDR，所有"发现"中假阳性的比例），适合因子挖掘 |
| 提高 t 统计量门槛 | Harvey, Liu & Zhu (2016) 建议新因子的 t 值至少超过 **3**，而不是 2 | 学术界对"因子动物园"的回应 |
| 样本外检验 | 留出从未用过的数据做最终检验 | **最可靠** |
| Deflated Sharpe Ratio | 根据尝试次数修正 Sharpe 比率 | López de Prado 提出 |

> **面试表达**：被问到"你怎么确认这个因子不是过拟合"时，提到**尝试了多少次**、**样本外表现**、**t 值门槛**、**经济学逻辑**这四点。

## 7. 线性回归（OLS）：必须能闭卷推导

### 7.1 模型

$$y_i=\beta_0+\beta_1x_{i1}+\cdots+\beta_px_{ip}+\varepsilon_i,\qquad\text{矩阵形式：}\ y=X\beta+\varepsilon$$

$y$ 是 $n\times1$，$X$ 是 $n\times(p+1)$（第一列全是 1，对应截距），$\beta$ 是 $(p+1)\times1$。

### 7.2 一元回归的推导

最小化残差平方和 $S(\beta_0,\beta_1)=\sum(y_i-\beta_0-\beta_1x_i)^2$：
- 对 $\beta_0$ 求偏导 = 0：$\hat\beta_0=\bar y-\hat\beta_1\bar x$（回归直线过点 $(\bar x,\bar y)$）
- 对 $\beta_1$ 求偏导 = 0：
$$\hat\beta_1=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2}=\frac{\widehat{\mathrm{Cov}}(x,y)}{\widehat{\mathrm{Var}}(x)}=r\cdot\frac{s_y}{s_x}$$

**必记结论**：
- 斜率 = 相关系数 × 标准差之比。
- 把 $x$、$y$ 都标准化后，斜率就是相关系数 $r$。
- 一元回归中 $R^2=r^2$。
- $y$ 对 $x$ 回归的斜率 $b_{y|x}=r\frac{s_y}{s_x}$，$x$ 对 $y$ 回归的斜率 $b_{x|y}=r\frac{s_x}{s_y}$，所以 $b_{y|x}\cdot b_{x|y}=r^2=R^2$（**往年·衍复/幻方考点**）。两条回归线**不是互为反函数**，除非 $|r|=1$。

### 7.3 矩阵形式的推导（面试常要求手推）

$$S(\beta)=(y-X\beta)^\top(y-X\beta)=y^\top y-2\beta^\top X^\top y+\beta^\top X^\top X\beta$$
对 $\beta$ 求导（矩阵求导规则见数学专题）：
$$\frac{\partial S}{\partial\beta}=-2X^\top y+2X^\top X\beta=0\ \Rightarrow\ \boxed{\hat\beta=(X^\top X)^{-1}X^\top y}$$
需要 $X^\top X$ 可逆，即 $X$ **列满秩**（没有完全共线性）。

**正规方程** $X^\top(y-X\hat\beta)=0$ 的含义：**残差与每一个自变量都正交**。推论：
- 有截距时，残差之和为 0；
- 残差与拟合值 $\hat y$ 正交。

### 7.4 几何解释

$\hat y=X\hat\beta=X(X^\top X)^{-1}X^\top y=Hy$。$H$ 称为**帽子矩阵**，是向 $X$ 的列空间的**正交投影**：
- $H^2=H$（投影两次等于投影一次），$H^\top=H$；
- $H$ 的特征值只有 0 和 1，$\mathrm{tr}(H)=\mathrm{rank}(X)=p+1$；
- 残差 $e=(I-H)y$ 与列空间正交。

**OLS 就是把 $y$ 投影到 $X$ 的列张成的空间上，残差是垂直的那部分。**

### 7.5 高斯-马尔可夫假设与 BLUE

| 编号 | 假设 | 作用 |
|---|---|---|
| A1 | 线性：$y=X\beta+\varepsilon$ | |
| A2 | $X$ 列满秩（无完全共线性） | $\hat\beta$ 存在且唯一 |
| A3 | 外生性：$E[\varepsilon\mid X]=0$ | **保证无偏**。最重要 |
| A4 | 同方差且无自相关：$\mathrm{Var}(\varepsilon\mid X)=\sigma^2I$ | 保证"最优"，以及标准误公式正确 |
| A5（可选） | $\varepsilon\sim N(0,\sigma^2I)$ | 小样本下 t、F 检验精确成立 |

**高斯-马尔可夫定理**：在 A1–A4 下，OLS 是**最优线性无偏估计（BLUE）**：在所有线性、无偏的估计量中方差最小。

### 7.6 无偏性与方差（必须会证）

代入 $y=X\beta+\varepsilon$：
$$\hat\beta=(X^\top X)^{-1}X^\top(X\beta+\varepsilon)=\beta+(X^\top X)^{-1}X^\top\varepsilon$$
- **无偏**：$E[\hat\beta\mid X]=\beta+(X^\top X)^{-1}X^\top E[\varepsilon\mid X]=\beta$（用了 A3）。
- **方差**：$\mathrm{Var}(\hat\beta\mid X)=(X^\top X)^{-1}X^\top(\sigma^2I)X(X^\top X)^{-1}=\sigma^2(X^\top X)^{-1}$（用了 A4）。
- **$\sigma^2$ 的无偏估计**：$\hat\sigma^2=\dfrac{\sum e_i^2}{n-p-1}$（估计了 $p+1$ 个参数，损失 $p+1$ 个自由度）。

一元回归中：$\mathrm{Var}(\hat\beta_1)=\dfrac{\sigma^2}{\sum(x_i-\bar x)^2}$。**$x$ 越分散、样本越多、噪声越小，斜率估计越准。**

### 7.7 拟合优度 $R^2$

$$\underbrace{\sum(y_i-\bar y)^2}_{\text{TSS 总平方和}}=\underbrace{\sum(\hat y_i-\bar y)^2}_{\text{ESS 解释平方和}}+\underbrace{\sum e_i^2}_{\text{RSS 残差平方和}}$$
$$R^2=\frac{ESS}{TSS}=1-\frac{RSS}{TSS}$$

- $R^2$ 是 $y$ 与 $\hat y$ 相关系数的平方。
- 加入任何新变量，$R^2$ **都不会下降**（最坏情况下系数取 0）。所以用**调整 $R^2$**：$\bar R^2=1-\frac{RSS/(n-p-1)}{TSS/(n-1)}$。
- 没有截距时，上面的分解不成立，$R^2$ 可能失去意义。
- **金融中 $R^2$ 很低是正常的**：日频收益预测的 $R^2$ 往往只有 1% 甚至更低，但已经很有价值。

### 7.8 系数的检验

- 单个系数：$t=\dfrac{\hat\beta_j}{\mathrm{SE}(\hat\beta_j)}\sim t_{n-p-1}$，$\mathrm{SE}(\hat\beta_j)=\sqrt{\hat\sigma^2[(X^\top X)^{-1}]_{jj}}$。
- 所有斜率是否同时为 0：$F=\dfrac{ESS/p}{RSS/(n-p-1)}\sim F_{p,\,n-p-1}$。

### 7.9 Frisch-Waugh-Lovell 定理（多元回归系数的含义）

在 $y=\beta_1x_1+\beta_2x_2+\varepsilon$ 中，$\hat\beta_1$ 等于下面两步的结果：
1. 把 $y$ 对 $x_2$ 回归，取残差 $\tilde y$；把 $x_1$ 对 $x_2$ 回归，取残差 $\tilde x_1$；
2. 把 $\tilde y$ 对 $\tilde x_1$ 回归。

**含义**：多元回归系数 = **剔除其他变量影响之后**，$x_1$ 对 $y$ 的作用。
**量化应用**：**因子中性化**就是这个思路——把因子对行业、市值回归取残差，得到"剔除了行业和市值影响"的纯因子。

## 8. 违反回归假设：后果与对策

> **面试最高频的追问区**。下表要做到能脱口而出。

| 问题 | 怎么发现 | 对 $\hat\beta$ 的影响 | 对标准误/检验的影响 | 对策 |
|---|---|---|---|---|
| **异方差** | 残差图呈喇叭形；White 检验、BP 检验 | 仍无偏、一致，但不再是 BLUE | **标准误错误**，t 检验失效 | 稳健标准误（White/HC）；加权最小二乘（WLS） |
| **自相关** | 残差 ACF 图；Durbin-Watson 检验 | 仍无偏（若无滞后因变量），不再 BLUE | **标准误通常被低估**，t 值虚高 | Newey-West 标准误（HAC）；建模自相关结构 |
| **多重共线性** | 系数符号奇怪、加减变量时系数大变；VIF > 10 | 仍无偏 | **方差大**、系数不稳定 | 删变量、合并变量、PCA、Ridge 回归 |
| **遗漏变量** | 理论分析 | **有偏且不一致** | | 加入遗漏变量；工具变量；面板固定效应 |
| **$x$ 有测量误差** | | 系数**向 0 偏**（衰减偏误） | | 工具变量；多次测量取平均 |
| **$y$ 有测量误差** | | 仍无偏 | 方差变大 | 一般问题不大 |
| **离群点** | 杠杆值、Cook 距离 | 可能被少数点主导 | | 去极值（winsorize）、稳健回归、用排名 |
| **非线性** | 残差图有规律 | 模型设定错误 | | 加入变换项、分段、树模型 |

### 8.1 遗漏变量偏误（必须会推）

真实模型 $y=\beta_1x_1+\beta_2x_2+\varepsilon$，但你只用 $x_1$ 回归。则
$$E[\tilde\beta_1]=\beta_1+\beta_2\cdot\delta,\qquad\delta=\frac{\mathrm{Cov}(x_1,x_2)}{\mathrm{Var}(x_1)}$$
偏误 = （遗漏变量的真实效应）×（遗漏变量对 $x_1$ 的回归系数）。只有当 $\beta_2=0$ 或 $x_1$、$x_2$ 不相关时才没有偏误。
**量化例子**：小市值股票的某个因子看起来有效，可能只是因为该因子和市值相关，而市值本身有效。所以要**做市值中性化**。

### 8.2 衰减偏误（Attenuation Bias）

真实 $x^*$，观察到 $x=x^*+u$（$u$ 是独立噪声）。则
$$\mathrm{plim}\ \hat\beta_1=\beta_1\cdot\frac{\mathrm{Var}(x^*)}{\mathrm{Var}(x^*)+\mathrm{Var}(u)}$$
系数被压向 0。**量化含义**：因子值本身是有噪声的估计，所以回归出的因子收益会被低估。

### 8.3 稳健标准误

- **White（HC）标准误**：$\widehat{\mathrm{Var}}(\hat\beta)=(X^\top X)^{-1}\Big(\sum e_i^2x_ix_i^\top\Big)(X^\top X)^{-1}$（"三明治"形式），在异方差下仍然正确。
- **Newey-West 标准误**：在此基础上还考虑了自相关。**量化中检验因子收益序列的均值是否显著，标准做法是用 Newey-West t 值。**

### 8.4 内生性

$E[\varepsilon\mid X]\ne0$，原因有三类：遗漏变量、测量误差、**反向因果/联立性**。后果都是 OLS **有偏且不一致**。经典对策是**工具变量（IV）**：找一个与 $x$ 相关、与 $\varepsilon$ 不相关的变量 $z$。（QR 面试了解概念即可。）

## 9. 回归的扩展

### 9.1 正则化

| 方法 | 目标函数 | 解 | 特点 |
|---|---|---|---|
| Ridge（L2） | $\lVert y-X\beta\rVert^2+\lambda\lVert\beta\rVert_2^2$ | $\hat\beta=(X^\top X+\lambda I)^{-1}X^\top y$ | 系数收缩但不为 0；解决共线性（$X^\top X+\lambda I$ 总可逆） |
| Lasso（L1） | $\lVert y-X\beta\rVert^2+\lambda\lVert\beta\rVert_1$ | 无闭式解（坐标下降） | 产生**稀疏解**，可做变量选择 |
| Elastic Net | L1 + L2 | | 兼顾两者，相关变量成组选入 |

- **为什么 Lasso 会产生 0**：L1 约束区域是菱形，有"尖角"落在坐标轴上，等高线容易先碰到尖角。L2 约束是圆，没有尖角。
- **贝叶斯解释**：Ridge ⇔ 系数有正态先验；Lasso ⇔ 系数有拉普拉斯先验。
- Ridge 的估计是**有偏的**，但方差更小（偏差-方差权衡）。
- 使用前要把变量**标准化**，否则惩罚对不同尺度的变量不公平。

### 9.2 逻辑回归

用于二分类（如预测明天涨跌）：$P(y=1\mid x)=\sigma(x^\top\beta)=\dfrac{1}{1+e^{-x^\top\beta}}$。
- 用 **MLE** 估计，损失函数是**交叉熵**（对数损失）。
- 为什么不用 MSE？因为配合 sigmoid 时 MSE 关于 $\beta$ 不是凸函数，有多个局部最优；交叉熵是凸的。
- 系数含义：$x_j$ 增加 1，**对数几率** $\ln\frac{p}{1-p}$ 增加 $\beta_j$。

### 9.3 加权最小二乘（WLS）

已知各观测的误差方差 $\sigma_i^2$ 不同时，最小化 $\sum w_i(y_i-x_i^\top\beta)^2$，取 $w_i=1/\sigma_i^2$。
**量化应用**：横截面回归中常用**市值的平方根**作为权重（大盘股收益的噪声相对小，且更能代表可投资的部分）——Barra 风险模型就是这样做的。

## 10. 协方差矩阵、PCA 与因子模型

### 10.1 协方差矩阵的性质

$\Sigma=\mathrm{Cov}(X)$，$\Sigma_{ij}=\mathrm{Cov}(X_i,X_j)$。
- **对称、半正定**：对任何权重 $w$，组合方差 $w^\top\Sigma w=\mathrm{Var}(w^\top X)\ge0$。
- $\mathrm{Var}(AX)=A\Sigma A^\top$。

### 10.2 样本协方差矩阵的问题

$N$ 只股票、$T$ 天数据。要估计 $\frac{N(N+1)}2$ 个参数。$N=3000$ 时约 450 万个参数。
- $N>T$ 时样本协方差矩阵**奇异**（不可逆），无法直接做组合优化。
- 即使 $N<T$，**最大特征值被高估、最小特征值被低估**，优化器会把重仓压在"看起来风险很低"但实际上是估计误差的方向上（**误差最大化**）。

**对策**：
1. **收缩估计**（Ledoit-Wolf）：$\hat\Sigma=\delta F+(1-\delta)S$，$S$ 为样本协方差，$F$ 为结构化目标（如单位阵的倍数、常相关矩阵），$\delta$ 由数据决定。
2. **因子模型**（Barra 的做法）：$r=Bf+u$，$\Sigma=B\Sigma_fB^\top+D$。只需估计少量因子协方差 $\Sigma_f$ 和对角的特质方差 $D$。
3. **PCA 降维**：只保留前几个主成分。

### 10.3 主成分分析（PCA）

1. 数据去均值（通常也标准化）；
2. 计算协方差矩阵 $\Sigma$ 并做特征分解 $\Sigma=V\Lambda V^\top$；
3. 特征向量是主成分方向，特征值是该方向上的方差；
4. 保留特征值最大的 $k$ 个，"解释方差比例" $=\sum_{i\le k}\lambda_i/\sum\lambda_i$。

**量化解释**：股票收益的第一主成分通常近似"**市场因子**"（所有股票同涨同跌），后面几个对应行业、风格。
**利率曲线**的前三个主成分是著名的"水平、斜率、曲率"。

## 11. 时间序列

### 11.1 平稳性

**（弱）平稳**：均值、方差不随时间变化，协方差只依赖于时间间隔：$\mathrm{Cov}(X_t,X_{t+k})=\gamma(k)$。
- **价格通常不平稳**（随机游走）；**收益率近似平稳**。所以建模用收益率而不是价格。
- 非平稳序列之间直接回归会产生**伪回归**：两个独立的随机游走，回归的 $R^2$ 常常很高、t 值很显著，但毫无意义。

### 11.2 自相关函数

- **ACF**：$\rho(k)=\gamma(k)/\gamma(0)$。
- **PACF**：剔除中间滞后项影响后，$X_t$ 与 $X_{t-k}$ 的相关。
- 识别：AR($p$) 的 PACF 在 $p$ 阶后截尾；MA($q$) 的 ACF 在 $q$ 阶后截尾。
- **Ljung-Box 检验**：检验前若干阶自相关是否同时为 0。

### 11.3 AR、MA、ARMA

**AR(1)**：$X_t=c+\phi X_{t-1}+\varepsilon_t$，$\varepsilon_t$ 是白噪声（方差 $\sigma^2$）。

| 性质 | 结论 |
|---|---|
| 平稳条件 | $\lvert\phi\rvert<1$ |
| 均值 | $\mu=\dfrac{c}{1-\phi}$ |
| 方差 | $\dfrac{\sigma^2}{1-\phi^2}$ |
| 自相关 | $\rho(k)=\phi^k$，指数衰减 |
| 半衰期 | $\dfrac{\ln0.5}{\ln\phi}$（偏离均值后衰减一半所需时间） |
| $\phi=1$ | 随机游走，非平稳（**单位根**） |

**量化含义**：$\phi<0$ 代表**反转**，$\phi>0$ 代表**动量**；均值回复策略（如配对交易）的价差最好是 $\phi$ 明显小于 1 的 AR(1)，半衰期决定持仓周期。

**MA(1)**：$X_t=\mu+\varepsilon_t+\theta\varepsilon_{t-1}$。只有 1 阶自相关 $\frac{\theta}{1+\theta^2}$，之后为 0。
**ARMA($p,q$)**：两者结合。**ARIMA**：先差分 $d$ 次再做 ARMA。

### 11.4 单位根检验与协整

- **ADF 检验**：$H_0$：有单位根（非平稳）。拒绝 $H_0$ 才说明平稳。
- **协整**：$X_t$、$Y_t$ 各自非平稳，但某个线性组合 $Y_t-\beta X_t$ 平稳。直观：两只股票价格各自随机游走，但被"一根橡皮筋"拴在一起。
- **配对交易**：找协整的股票对，价差偏离均值时做空高的、做多低的。检验方法：Engle-Granger 两步法（先回归，再对残差做 ADF）或 Johansen 检验。
- **注意**：相关性高 ≠ 协整。相关性描述收益（短期同涨同跌），协整描述价格（长期不分离）。

### 11.5 波动率模型：GARCH

金融收益的典型特征：**波动率聚集**（大波动后面跟着大波动），收益本身几乎无自相关，但**收益的平方有很强的自相关**。

**GARCH(1,1)**：
$$r_t=\sigma_t z_t,\qquad\sigma_t^2=\omega+\alpha r_{t-1}^2+\beta\sigma_{t-1}^2$$
- 平稳条件 $\alpha+\beta<1$；长期（无条件）方差 $\dfrac{\omega}{1-\alpha-\beta}$；
- $\alpha+\beta$ 衡量波动率冲击的持续性，实际数据常在 0.95–0.99。
- **EWMA**（RiskMetrics）是特例：$\sigma_t^2=\lambda\sigma_{t-1}^2+(1-\lambda)r_{t-1}^2$，日频常取 $\lambda=0.94$。

### 11.6 时间序列的量化常识

- 波动率年化：$\sigma_{年}=\sigma_{日}\sqrt{252}$；收益年化：$\mu_{年}=252\,\mu_{日}$。
- **前视偏差**：任何时刻只能用该时刻之前的数据。滚动窗口估计、标准化都要注意。
- **重叠样本**：用 20 日收益做日频回归，相邻样本高度重叠，产生强自相关，标准误要用 Newey-West 修正。

## 12. 贝叶斯统计入门

$$\underbrace{p(\theta\mid\text{数据})}_{\text{后验}}\ \propto\ \underbrace{p(\text{数据}\mid\theta)}_{\text{似然}}\cdot\underbrace{p(\theta)}_{\text{先验}}$$

- **频率学派**：参数是固定的未知常数，概率是长期频率。
- **贝叶斯学派**：参数是随机变量，概率是信念程度。

**共轭先验**（后验与先验同类型，计算方便）：

| 似然 | 先验 | 后验 |
|---|---|---|
| 二项（$k$ 次成功、$m$ 次失败） | Beta($a,b$) | Beta($a+k,\ b+m$) |
| 正态（方差已知） | 正态 | 正态：后验均值是先验均值和样本均值的**精度加权平均** |
| 泊松 | Gamma | Gamma |

**正态-正态的例子**：先验 $\mu\sim N(\mu_0,\tau^2)$，数据 $\bar x$ 的方差 $\sigma^2/n$，则后验均值
$$\frac{\mu_0/\tau^2+\bar x\cdot n/\sigma^2}{1/\tau^2+n/\sigma^2}$$
数据越多，越相信数据；先验越确定，越相信先验。
**量化应用**：**收缩估计**（对预期收益、Sharpe、因子 IC 向某个先验值收缩）、Black-Litterman 模型。

## 13. 重抽样与交叉验证

- **Bootstrap**：从样本中**有放回**地重抽 $n$ 个，重复很多次，用重抽样统计量的分布近似估计量的抽样分布。用途：求复杂统计量（如 Sharpe 比率、中位数）的置信区间。
  - 时间序列要用**块自助法**（block bootstrap）保留自相关结构。
- **交叉验证**：把数据分成 $K$ 份，轮流用 $K-1$ 份训练、1 份验证。
  - **金融时间序列不能随机打乱做 K 折**。否则会用未来数据训练、过去数据验证，造成信息泄漏。
  - 正确做法：**滚动/扩展窗口**（walk-forward），或 López de Prado 的 **Purged K-Fold + Embargo**（删除训练集和验证集之间标签重叠的样本，并留出间隔），详见[机器学习](../machine-learning/notes.md)第 3 节。

## 14. 统计在量化中的应用

### 14.1 IC 与 IR

- **IC（信息系数）**：某一期，所有股票的因子值与下一期收益的截面相关系数。用排名算就是 **Rank IC**。
- 一般来说，日频 A 股量价因子的 |Rank IC| 均值在 0.03–0.10 已经算不错（具体视因子和样本而定）。
- **ICIR** $=\dfrac{\text{IC 均值}}{\text{IC 标准差}}$，衡量因子预测能力的**稳定性**。
- **IC 的 t 值** $=\text{ICIR}\times\sqrt{T}$（$T$ 为期数），检验 IC 均值是否显著不为 0。

**主动管理基本定律**（Grinold）：$IR\approx IC\times\sqrt{\text{Breadth}}$。Breadth 是独立下注的次数。含义：**预测能力弱没关系，只要下注足够多、足够独立**——这就是为什么量化选股要覆盖几千只股票。

### 14.2 Sharpe 比率

$$SR=\frac{E[r-r_f]}{\sigma(r)},\qquad SR_{年}=SR_{日}\times\sqrt{252}$$

- **Sharpe 与 t 统计量的关系**：检验策略平均收益是否为 0，$t=\frac{\bar r}{s/\sqrt T}=SR_{日}\sqrt{T_{日}}=SR_{年}\sqrt{\text{年数}}$。
  - 年化 Sharpe 1.0、回测 4 年，$t=2$，勉强显著。
  - 年化 Sharpe 0.5、回测 4 年，$t=1$，和噪声无法区分。
- **Sharpe 的标准误**（独立同分布正态收益）：$\mathrm{SE}(\widehat{SR})\approx\sqrt{\dfrac{1+SR^2/2}{T}}$（$SR$ 与 $T$ 用同一频率）。
- Sharpe 的局限：只看均值和方差，忽略偏度和厚尾。负偏策略（如卖期权）Sharpe 可能很漂亮但有崩盘风险。

### 14.3 回测的统计陷阱清单

| 陷阱 | 说明 |
|---|---|
| 前视偏差 | 用了当时还不知道的数据（财报发布日、复权方式、指数成分） |
| 幸存者偏差 | 只用现存股票，忽略已退市的 |
| 多重检验 | 试了很多次只报告最好的 |
| 过拟合 | 参数多、样本少；样本内很好、样本外很差 |
| 数据窥探 | 看过全样本结果后再"设计"策略 |
| 交易成本 | 忽略佣金、印花税、冲击成本、涨跌停无法成交 |
| 非平稳 | 市场结构变化，过去有效未来未必有效 |

## 15. 面试高频问题速查

| 问题 | 要点 |
|---|---|
| 样本方差为什么除以 $n-1$？ | 用 $\bar X$ 代替 $\mu$ 损失 1 个自由度；$E[\sum(X_i-\bar X)^2]=(n-1)\sigma^2$ |
| p 值是什么？ | $H_0$ 为真时，看到至少这么极端结果的概率；不是 $H_0$ 为真的概率 |
| 推导 OLS | $\hat\beta=(X^\top X)^{-1}X^\top y$；见 7.3 |
| OLS 的假设？违反了会怎样？ | 7.5 和第 8 节表格 |
| 证明 OLS 无偏，求其方差 | 7.6 |
| $R^2$ 是什么？能为负吗？ | 解释方差比例；有截距的 OLS 样本内不会为负；样本外或无截距时可以为负 |
| 加一个变量 $R^2$ 怎么变？ | 不会下降；用调整 $R^2$ |
| 数据复制一份再回归，系数和标准误怎么变？ | 系数不变，标准误约缩小为 $1/\sqrt2$（虚假的精确） |
| $y$ 对 $x$ 和 $x$ 对 $y$ 的回归斜率关系？ | 乘积 $=r^2=R^2$ |
| 多重共线性的后果？ | 无偏但方差大、系数不稳定；预测能力不一定变差 |
| 异方差的后果？ | 系数无偏，标准误错误；用 White 标准误 |
| 为什么要中性化？ | 遗漏变量偏误 / FWL：剔除行业、市值等已知因素 |
| MLE 和 OLS 的关系？ | 正态误差下二者一致 |
| Ridge 和 Lasso 的区别？ | L2 收缩、L1 稀疏；对应正态和拉普拉斯先验 |
| 什么是平稳？为什么重要？ | 统计性质不随时间变；非平稳序列回归会产生伪回归 |
| 相关和协整的区别？ | 收益的同步性 vs 价格的长期均衡 |
| 怎么判断一个因子是否有效？ | IC/ICIR、t 值（>3 更可靠）、分层回测单调性、样本外、换手与成本、经济逻辑 |
| Sharpe 1 的策略需要多少年才能显著？ | $t=SR\sqrt{\text{年数}}$，约 4 年达到 $t=2$，9 年达到 $t=3$ |
